# Portfolio

Personal product portfolio of Ajanth Sri Kathirkamanthan, deployed on Vercel.

- `src/source.html` holds all the content.
- `python3 build.py` generates the home page, the About page, one page per tool in `work/`, and the shared `assets/`.
- Commit the generated files. Vercel serves them as static pages, with clean URLs from `vercel.json`.
